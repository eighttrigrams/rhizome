# Rhizome - User Manual

## Features

Rhizome has many features which are not obvious
to find. Here's a small listing

### Linking to other Items from the description of one Item

Put `[<id-of-other-item](link text)` into the markdown text  
of one Item and it becomes a clickable link to that other Item.
The other Item will become the selected item, and `option-b` will
bring you back to the original Item.

### YouTube videos support

#### Subscribing to YouTube channels (feed)

Press shift+option+s to reach the configuration view  
(where you can also add atom feed subscriptions).

#### QR Codes

YouTube videos will be presented with a QR code below them,  
which allows you to jump to that video with your phone.

### Hierarchy mode

Access with shift+option+h.
